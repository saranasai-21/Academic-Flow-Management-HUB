## 📖 About the Project

Academic Flow Management HUB is a web-based platform developed to improve the management of academic activities within educational institutions. The application provides an organized environment for handling academic workflows, user management, and institutional operations.

The project follows a full-stack architecture with a React frontend and a Node.js/Express backend, enabling scalable and maintainable development.

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- Node.js (v18 or higher)
- npm
- MongoDB

---

### Clone Repository

```bash
git clone https://github.com/saranasai-21/Academic-Flow-Management-HUB.git

cd Academic-Flow-Management-HUB
```

---

## Frontend Setup

```bash
cd frontend

npm install

npm run dev
```

Frontend runs on:

```text
http://localhost:5173
```

---

## Backend Setup

```bash
cd backend

npm install

npm run dev
```

or

```bash
npm start
```

Backend runs on:

```text
http://localhost:5000
```

---

## ⚙️ Environment Variables

Create a `.env` file inside the backend directory.

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key
```

---

## 📡 API Structure

The backend follows a standard MVC architecture:

### Configuration

```text
backend/config/
```

Contains database connection and application configuration.

### Controllers

```text
backend/controllers/
```

Contains business logic for handling requests.

### Models

```text
backend/models/
```

Defines MongoDB schemas using Mongoose.

### Routes

```text
backend/routes/
```

Contains API endpoint definitions.
